# NELEV 1.9.13 - Краткая сводка исправлений

## Проблемы, которые были исправлены:

### 1. Дёрганье окна при изменении размера ❌ → ✅
**Было:** При переходе с "Свой срок" на другие пункты окно резко дёргалось  
**Стало:** Плавное изменение размера с spring анимацией через `animateContentSize`

### 2. Телепортация плашки выбора ❌ → ✅
**Было:** Плашка мгновенно перескакивала между пунктами  
**Стало:** Плашка плавно "переплывает" с spring анимацией через `animateDpAsState`

### 3. Дёрганье "Что нового" ❌ → ✅
**Было:** Окно прыгало при раскрытии changelog  
**Стало:** Плавное раскрытие через `animateContentSize` вместо `AnimatedVisibility`

### 4. Неправильная локализация changelog ❌ → ✅
**Было:** На русском всё работало, на других языках - нет  
**Стало:** Все языки загружают правильные переводы из `version_history.json`

## Технические детали:

- **animateContentSize** с spring для плавного изменения размера
- **animateDpAsState** для плавного движения плашки
- **Spring.DampingRatioMediumBouncy** - лёгкий bounce для плашки
- **Spring.DampingRatioNoBouncy** - без bounce для изменения размера
- Offset плашки: `(selectedIndex * 44).dp` где 44dp - высота пункта
