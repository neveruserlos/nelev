**Файл:** `MainActivity.kt` (строки 8404-8560)

### 2. ✅ Плавное "переплывание" плашки активного пункта
**Проблема:** При выборе разных периодов плашка телепортировалась без плавного перехода

**Решение:**
- Создал отдельный анимированный `Box` который служит фоном для выбранного пункта
- Используется `animateDpAsState` для плавного изменения `offset.y`
- Spring анимация с `Spring.DampingRatioMediumBouncy` и `Spring.StiffnessMedium`
- Плашка теперь плавно "переплывает" от одного пункта к другому
- Высота каждого пункта: 44.dp, offset рассчитывается как `(selectedPauseOption * 44).dp`

**Техническая реализация:**
```kotlin
val selectedOffset by animateDpAsState(
    targetValue = if (selectedPauseOption != null) (selectedPauseOption!! * 44).dp else 0.dp,
    animationSpec = spring(
        dampingRatio = Spring.DampingRatioMediumBouncy,
        stiffness = Spring.StiffnessMedium
    )
)

Box(
    Modifier
        .offset(y = selectedOffset + 10.dp)
        .fillMaxWidth()
        .height(44.dp)
        .background(colors["accent"]!!.copy(alpha = 0.12f))
        .border(1.dp, colors["accent"]!!.copy(alpha = 0.35f))
)
```

**Файл:** `MainActivity.kt` (строки 8439-8456)

## 📊 Технические детали

### Использованные анимации:

**animateContentSize:**
- Плавное изменение размера контейнера
- Spring анимация без bounce эффекта
- Автоматически анимирует любые изменения размера детей

**animateDpAsState:**
- Плавная анимация offset для "переплывающей" плашки
- Spring с лёгким bounce эффектом для естественности
- Рассчитывается динамически на основе индекса выбранного пункта

**Spring параметры:**
- `DampingRatioNoBouncy` - без отскока (для изменения размера)
- `DampingRatioMediumBouncy` - средний отскок (для плашки)
- `StiffnessMediumLow` - низкая жёсткость (плавное движение)
- `StiffnessMedium` - средняя жёсткость (быстрее, но плавно)
