# Три исправления для NELEV 1.9.13

## Проблема 1: Криво расположенная плашка выбора ❌ → ✅

**Было:**
Плашка находилась не на выбранных пунктах, смещена вниз

**Исправлено:**
- Изменён расчёт offset: `(index * 52).dp` вместо `(index * 44).dp`
- 52dp учитывает spacing между пунктами (44dp высота + 8dp gap)
- Убран лишний offset `+ 10.dp`

---

## Проблема 2: Дёрганье при раскрытии "Что нового" в уведомлении ❌ → ✅

**Было:**
Текст changelog раскрывался максимально дёргано

**Исправлено:**
- Заменил `animateContentSize` на `AnimatedVisibility`
- Добавлены `expandVertically` + `fadeIn` для плавного появления
- `shrinkVertically` + `fadeOut` для плавного скрытия
- Spring анимация для естественного движения

---

## Проблема 3: Телепание окна "Что нового" вниз ❌ → ✅

**Было:**
Окно плавно идёт вверх, потом резко телепается чуть вниз

**Исправлено:**
- Обернул Surface в Box с `wrapContentHeight()`
- Box стабилизирует позицию во время анимации Dialog
- `contentAlignment = Alignment.Center` для правильного центрирования
- Теперь окно плавно появляется без рывков
