## ✅ Все исправления выполнены

### 1. Локализация уведомлений при смене языка
**Проблема:** Уведомления о проверке обновлений не меняли язык при смене языка в настройках.

**Решение:**
- В функции `checkUpdates` добавлено получение `currentLang` из `appSettings.value.language`
- Используется актуальный язык вместо статичной переменной `lang`

**Файл:** `MainActivity.kt` (строка 3621-3640)

**Результат:** Уведомления "Проверка обновлений..." и "У вас последняя версия" теперь отображаются на выбранном языке.

---

### 2. Плавная анимация выбора периодов в окне паузы
**Проблема:** При выборе разных периодов (1 неделя, 2 недели и т.д.) переход был резким без анимации.

**Решение:**
- Добавлен `animateColorAsState` для фона и границ каждого варианта
- Время анимации: 250ms с `FastOutSlowInEasing`
- Плавный переход цвета при выборе/отмене выбора
- Внутренний кружок радиокнопки анимируется через `AnimatedVisibility` с `scaleIn/scaleOut`

**Файл:** `MainActivity.kt` (строки 8408-8466)

**Результат:** Плавные цветовые переходы при выборе периодов, радиокнопки анимируются с эффектом масштаба.

---

### 3. Плавное расширение поля "Свой срок"
**Проблема:** Поле для ввода дней появлялось резко без анимации.

**Решение:**
- Обёрнуто в `AnimatedVisibility` вместо простого `if`
- `expandVertically` (320ms) + `fadeIn` (250ms) при появлении
- `shrinkVertically` (280ms) + `fadeOut` (200ms) при скрытии
- `FastOutSlowInEasing` для естественного движения

**Файл:** `MainActivity.kt` (строки 8467-8513)

**Результат:** Поле плавно раскрывается вниз с появлением при выборе "Свой срок".

---

### 4. Исправлен баг с закрытием окна без выбора
**Проблема:** Если выбрать "Свой срок", не ввести количество дней и закрыть окно, то при следующем открытии оставался выбран "Свой срок".

**Решение:**
- Добавлен сброс `selectedPauseOption = null` и `customDays = ""` при закрытии окна
- Сброс добавлен в 3 места:
  - `BackHandler` (строка 7772-7781)
  - Клик на фон (строка 7783-7796)
  - Кнопка закрытия (строка 7876-7887)

**Файл:** `MainActivity.kt`

**Результат:** Состояние всегда сбрасывается при закрытии окна, следующее открытие начинается с чистого листа.

---

### 5. Убрано телепортирование окна при раскрытии changelog
**Проблема:** При нажатии стрелочки "Что нового" в диалоге обновления окно слегка "прыгало" или "телепортировалось".

**Решение:**
- Убран лишний `Column` wrapper внутри `AnimatedVisibility`
- Текст changelog теперь напрямую в `AnimatedVisibility` с `modifier = Modifier.fillMaxWidth()`
- Добавлен `modifier = Modifier.fillMaxWidth()` к родительскому `Column`

**Файл:** `UpdateDialog.kt` (строки 152-204)

**Результат:** Плавное раскрытие без рывков и смещения позиции окна.

---

### 6. Динамическая загрузка переводов "Что нового"
**Проблема:** При смене языка в окне "Что нового" текст оставался на старом языке.

**Решение:**
- Добавлен второй `LaunchedEffect` который реагирует на изменение языка
- При смене `appSettings.value.language` перезагружается changelog на новом языке
- Вызов `VersionHistory.changelog(ctx, versionCode, lang)` с параметром языка

**Файл:** `MainActivity.kt` (строки 2292-2313)

**Результат:** При смене языка текст "Что нового" мгновенно обновляется на выбранный язык.

## 🔧 Технические детали

### Использованные API Compose:
- `animateColorAsState` - плавные цветовые переходы
- `AnimatedVisibility` с `expandVertically`/`shrinkVertically` - расширение поля
- `scaleIn`/`scaleOut` - анимация радиокнопки
- `LaunchedEffect` с зависимостью от языка - реактивная загрузка
- `FastOutSlowInEasing` - естественное движение

### Время анимаций:
- Цветовые переходы: 250ms
- Расширение поля: 320ms (expand), 280ms (shrink)
- Fade эффекты: 250ms (in), 200ms (out)
- Масштабирование: 150ms
