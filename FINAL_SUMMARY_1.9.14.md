## Три основные проблемы и решения

### Проблема 1: Криво расположенная плашка выбора
**Симптомы:** Плашка не совпадает с пунктами, смещена вниз

**Причина:** 
- Неправильный расчёт offset: использовалось `index * 44` (только высота)
- Не учитывался spacing между пунктами (8dp)
- Лишний offset `+ 10.dp` смещал плашку ещё ниже

**Решение:**
```kotlin
val selectedOffset by animateDpAsState(
    targetValue = (selectedPauseOption!! * 52).dp,  // 44 + 8 spacing
    ...
)
Box(Modifier.offset(y = selectedOffset))  // без +10.dp
```

---

### Проблема 2: Дёрганье при раскрытии "Что нового" в уведомлении
**Симптомы:** Текст changelog раскрывается максимально дёргано

**Причина:**
- `animateContentSize` на всём Column вызывает пересчёт всего контейнера
- Появление/исчезновение через `if` создаёт резкие скачки размера

**Решение:**
```kotlin
// Вместо animateContentSize на Column
AnimatedVisibility(
    visible = showNotes,
    enter = expandVertically(spring(...)) + fadeIn(),
    exit = shrinkVertically(spring(...)) + fadeOut()
) {
    Text(info.changelog, ...)
}
```

---

### Проблема 3: Телепание окна "Что нового" вниз
**Симптомы:** Окно плавно идёт вверх, потом резко телепается чуть вниз

**Причина:**
- Dialog имеет системную анимацию появления
- Surface пересчитывает размер во время анимации
- Позиция "прыгает" после завершения системной анимации

**Решение:**
```kotlin
Dialog(onDismissRequest = onDismiss) {
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .wrapContentHeight(),  // Стабилизирует позицию
        contentAlignment = Alignment.Center
    ) {
        Surface(...) { ... }
    }
}
```

## Технические параметры

**Плашка выбора:**
- Высота пункта: 44dp
- Spacing между пунктами: 8dp (из `Arrangement.spacedBy(8.dp)`)
- Формула offset: `index * (44 + 8) = index * 52`
- Spring: DampingRatioMediumBouncy для bounce эффекта

**Раскрытие changelog:**
- AnimatedVisibility вместо animateContentSize
- expandVertically для появления
- shrinkVertically для скрытия
- fadeIn/fadeOut для плавности
- Spring: DampingRatioNoBouncy, StiffnessMediumLow

**Стабилизация окна:**
- Box с wrapContentHeight() вокруг Surface
- contentAlignment = Alignment.Center
- Предотвращает пересчёт позиции во время анимации
